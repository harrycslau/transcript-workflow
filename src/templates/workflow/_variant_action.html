{% comment %} Shared per-variant Generate/Retry/Regenerate action form. Expects: variant (read-only variant view-model), recording, actions (fingerprint availability), and optionally return_view (server-owned page token: "detail" | "summary" — set by the including template). A section-scoped page sets ``action_url`` (the POST route) and renders ``actions.fingerprint`` if available, else ``section_actions.fingerprint``. Renders NOTHING when the selected read selector cannot map to an approved generation selector (variant.action_selector is None) — a concrete read-only tab such as a historical Finnish variant never submits itself as a generation target. The form posts: - language: the GENERATION selector (default/original/en/zh-Hant only); - return_language: the read selector to keep the selected tab after the action (validated against the read-only view-model by the view); - return_view: the page to return to (allowlist token, never a URL); - mode: the expected per-language action mode. Both the recording-level and the section-scoped summarize forms execute their action on this first POST (no server-side confirmation step), so both carry the pending-state hooks (``data-action-form`` marker + ``aria-live`` status region) for the submit JavaScript.
