Weekly product sync — AI features roadmap

Overview
The team discussed the Q4 product roadmap with a focus on AI-powered features. Key decisions included prioritising local LLM integration for privacy-sensitive use cases, improving on-device speech recognition accuracy, and adopting a hybrid approach where cloud services are optional rather than required. Budget allocation and timeline milestones were agreed upon.
Key points
  1. Local LLM integration is the top priority for Q4, with a target of running 7B-parameter models on consumer hardware within existing memory constraints.
  2. On-device speech recognition should achieve <5% WER for English and <15% for Cantonese by end of Q4 through fine-tuning on domain-specific data.
  3. Cloud services will remain optional — all core features must work offline. Cloud is used only for heavy batch processing and model updates.
  4. Budget approved: 40% engineering, 30% data collection, 20% testing, 10% documentation. Total envelope is within the previously discussed range.
  5. Privacy review checkpoint scheduled for mid-October before any external-facing features ship.
