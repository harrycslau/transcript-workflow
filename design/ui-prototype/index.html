Overview

The team discussed the Q4 product roadmap with a focus on AI-powered features. Key decisions included prioritising local LLM integration for privacy-sensitive use cases, improving on-device speech recognition accuracy, and adopting a hybrid approach where cloud services are optional rather than required. Budget allocation and timeline milestones were agreed upon.

Key points

  1. Local LLM integration is the top priority for Q4.
    1. Target running 7B-parameter models on consumer hardware within existing memory constraints.
    2. Quantise to 4-bit to fit within 8 GB of unified memory on M-series chips.
    3. Keep cloud services optional, never required, for privacy-sensitive use cases.
  2. On-device speech recognition accuracy should improve substantially by end of Q4.
    1. English target: below 5% WER.
    2. Cantonese target: below 15% WER through domain-specific fine-tuning.
    3. Collect conversational Cantonese with English code-switching for training.
  3. Budget and timeline were agreed.
    1. 40% engineering, 30% data collection, 20% testing, 10% documentation.
    2. Prototype by mid-October, beta by late November, release before year end.
